# Besvarelser og modelltekster

Hver fil er en besvarelse eller modelltekst. Metadata står øverst i filen.

| Felt | Betydning |
|---|---|
| `tittel` | Tittel på teksten |
| `type` | `retorisk-analyse`, `novelleanalyse`, `diktanalyse`, `reflekterende-tekst` eller `droftende-tekst` |
| `nivaa` | `modelltekst`, eller karakter/nivå for en elevbesvarelse |
| `status` | `utkast` eller `godkjent` |
| `oppgave` | Oppgaven teksten svarer på |
| `forfatter`, `lisens`, `lisensUrl`, `kilde` | Opphav og lisens. Må fylles ut for tekster andre har skrevet. |

Tekster under Creative Commons må vises med navn på forfatter, lisens og lenke til kilden. Ved CC BY-SA må også bearbeidelser (for eksempel øvelser som bruker teksten) deles på samme lisens.

Elevbesvarelser må være anonymisert og ha samtykke før de legges inn. Repoet er åpent, så alt som legges her blir offentlig.
