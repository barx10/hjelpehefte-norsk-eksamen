Retteprogrammet fanger ikke alt. Her er feil som går igjen.

## Skriv i to ord

| Feil | Riktig |
|---|---|
| idag | i dag |
| imorgen | i morgen |
| igår | i går |
| tilslutt | til slutt |
| forexempel | for eksempel |

## Skriv i ett ord

Sammensatte ord skrives som ett ord: **eksamensoppgave**, ikke «eksamen oppgave». Det gjelder for eksempel diktanalyse, språkbruk og avisartikkel.

## Liten eller stor forbokstav

- **Liten forbokstav:** ukedager (mandag), måneder (mai), språk (norsk, engelsk) og folkeslag (nordmann).
- **Stor forbokstav:** navn på personer og steder (Oslo, Norge), og første ord etter punktum.

## Ofte forvekslede ord

| Ord | Regel | Eksempel |
|---|---|---|
| å / og | «å» står foran verb (å lese). «og» binder sammen. | «Jeg liker å lese og skrive.» |
| de / dem | «de» er subjekt. «dem» er objekt. | «De ser meg.» «Jeg ser dem.» |
| hver dag / hverdag | «hver dag» betyr alle dager. «hverdag» er en vanlig dag, ikke helg. | «Jeg leser hver dag.» |
| når / nå | «når» spør om tid eller innleder en leddsetning. «nå» betyr i dette øyeblikket. | «Når kommer du?» «Jeg kommer nå.» |
| også / og så | «også» betyr i tillegg. «og så» betyr og deretter. | «Jeg vil også ha is.» «Vi spiste, og så gikk vi.» |
| vært / hvert | «vært» kommer av å være. «hvert» betyr hvert eneste. | «Jeg har vært syk.» «Det skjer hvert år.» |
| ligge / legge | «ligge» er å være i ro. «legge» er å plassere noe. Preteritum er «lå» og «la». | «Boka ligger på bordet.» «Jeg legger boka på bordet.» |
| sitte / sette | «sitte» er å være i ro. «sette» er å plassere noe eller seg. Preteritum er «satt» og «satte». | «Hun sitter.» «Hun setter seg.» |
| noe / noen | «noe» brukes om ting og om det du ikke kan telle. «noen» brukes om personer og om flere ting. | «Har du noe mat?» «Noen ringte.» |
| enda / ennå | Foran et ord som sammenligner, skal det stå «enda». | «Den nye filmen er enda bedre.» |

**Ligge eller legge?** Spør om noen gjør noe med en ting. Gjør de det, er det «legge» og «sette»: «Hun legger telefonen bort.» Er tingen bare der, er det «ligge» og «sitte»: «Telefonen ligger der.»
