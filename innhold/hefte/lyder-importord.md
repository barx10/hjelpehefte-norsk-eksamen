Norsk skrives ikke alltid slik det uttales. Her er de vanligste lydene og bokstavene som skaper problemer.

## Stumme bokstaver

Noen bokstaver skrives, men uttales ikke.

| Stum bokstav | Eksempler |
|---|---|
| **h** foran v | hva, hvem, hvor, hvorfor, hvilken, hvis, hvit |
| **g** foran j | gjest, gjøre, gjerne, gjennom |
| **h** foran j | hjem, hjelpe, hjerte, hjul |
| **d** etter l, n og r | kald, land, ord, bord, vind |
| **g** i -ig og -lig | viktig, dårlig, egentlig, vennlig |
| **g** i småord | og, jeg, meg, deg, seg |
| **t** i bestemt form | huset, eplet, det |

**Tips for -ig og -lig:** Bøy ordet. I «viktige» og «dårlige» hører du g-en.

## Kj- og sj-lyden

Kj-lyden og sj-lyden kan skrives på flere måter.

| Lyd | Skrivemåte | Eksempler |
|---|---|---|
| kj-lyden | kj | kjøre, kjenne, kjole |
| | k foran i, y og ei | kino, kysse, keiser |
| | tj | tjue, tjern |
| sj-lyden | sj | sjø, sju, sjokolade |
| | skj | skjære, skjorte, skjelve |
| | sk foran i, y, øy og ei | ski, sky, skøyte, skeiv |
| | -sjon i importord | stasjon, situasjon, informasjon |

Det heter **kino** og **ski**, ikke «kjino» og «skji». Foran i og y trenger du ikke j.

## Forstavelser og endelser

**Forstavelser** skrives sammen med resten av ordet: **be**tale, **for**klare, **u**enig, **mis**forstå.

**Endelser** har faste skrivemåter.

| Endelse | Eksempler | Husk |
|---|---|---|
| -lig | vennlig, ærlig, egentlig | Stum g: ikke «egentli» |
| -ig | viktig, ferdig, deilig | Stum g |
| -het | frihet, sannhet | Flertall: friheter |
| -else | følelse, opplevelse | |
| -skap | vennskap, vitenskap | |
| -sjon | situasjon, diskusjon | Ikke «-tion» som på engelsk |
| -isk | typisk, fantastisk | |
| -ere (verb) | studere, reagere | Preteritum: studerte, reagerte |

## Importord

Mange ord fra andre språk er tilpasset norsk skrivemåte. Bruk den norske formen.

| Norsk skrivemåte | Ikke |
|---|---|
| sjanger | genre |
| sjåfør | chauffeur |
| byrå | bureau |
| nivå | niveau |
| miljø | milieu |
| e-post | email |
| garasje | garage |
| kafé | café |

**Eksamensord som ofte staves feil:**

> interessant, spesiell, absolutt, akkurat, forskjellig, egentlig, kanskje, diskusjon, kommentar, kommunikasjon, argument, konklusjon, sammenligne, kjærlighet
