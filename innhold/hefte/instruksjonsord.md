Les instruksjonsordet nøye. Det styrer hva du skal gjøre.

| Instruksjonsord | Hva det betyr |
|---|---|
| Gjør rede for | Forklar. Hva er det? Hvordan fungerer det? |
| Argumenter | Kom med grunner for eller mot noe. Vær saklig, men du kan bruke retoriske virkemidler. |
| Drøft / diskuter | Se saken fra begge sider. Kom med argumenter for og mot. |
| Analyser | Gå inn i teksten: virkemidler, formål, målgruppe, effekt. |
| Reflekter | Tenk gjennom temaet fra flere vinkler. Bruk egne erfaringer. |
| Vurder | Ta stilling. Si hva du mener og begrunn det. |
| Sammenlign | Finn likheter og forskjeller mellom to tekster eller fenomener. |
